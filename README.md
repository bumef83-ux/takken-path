# TAKKEN PATH

宅建試験向けの、スマートフォン対応学習支援PWAです。

## 主な機能

- 試験日から逆算した学習計画の自動生成
- LEC「2026 イチから身につく 宅建士合格のトリセツ 基本テキスト」を軸にしたインプット計画
- 基本テキスト4分野の読了率管理
- 2026年6月11日から試験前日までの単元別ロードマップ
- 平日120分・休日210分（週17時間、約300時間）の推奨学習設定
- Web申込、郵送締切、受験票、試験日、合格発表のアプリ内リマインド
- 重要日程を端末カレンダーへ登録できるICS出力
- 日曜の復習日に、宅建吉野塾の該当講義を任意の補強課題として表示
- 学習曜日・1日あたりの時間設定
- 今日のタスクと完了記録
- 科目別進捗、直近7日間の学習量、連続学習日数
- オリジナル一問一答と復習リスト
- 25分集中タイマー
- 端末内保存、オフライン利用、学習データ書き出し

## 起動方法

`index.html` を直接開いても使えます。PWA機能を含めて確認する場合は、このフォルダでローカルHTTPサーバーを起動してください。

```powershell
python -m http.server 4173
```

その後、ブラウザで `http://localhost:4173` を開きます。

## 注意

収録問題は動作確認用のオリジナル例題です。実際の受験学習では、法改正に対応した最新教材と公式情報を併用してください。

学習順序は、不動産適正取引推進機構の公式日程、アガルートの半年・短期学習記事、オンスクの6月開始学習記事、2026年度向け宅建講師YouTube動画を比較して設計しています。

LECトリセツを主教材とし、吉野塾は「宅建業法の安定得点」「法令上の制限」「2026年度改正点」の補強に限定しています。
